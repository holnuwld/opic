## 📌 Background Survey 핵심 요약 & 출제 전략

* OPIc의 개인 맞춤형 문제는 **Background Survey(배경 설문)** 응답을 기초로 출제됩니다.
* **필기 팁:**  
  - 직업은 **"일 경험 없음"**, 학생 여부는 **"아니오 (수업 등록 후 5년 이상 지남)"**를 선택하여 직장 및 학교 관련 까다로운 돌발 질문을 원천 차단합니다.
  - 선택 항목(4번 문항)에서 총 **12개 이상**을 전략적으로 선택하여 서베이 기반 질문의 출제 범위를 좁히고 준비된 스크립트(가족, 음악, 영화, 여행, 해변 등)를 유도합니다.
  - **시험 문제 구성:** 전체 15문항 중 **주제는 총 5개**이며, 이 중 **Survey 기반 3개 세트(3콤보) / 돌발 2개 세트(3콤보)**로 출제됩니다. (롤플레이 포함)

## 🎯 선택된 12개 항목과 준비 스크립트 매핑표

| 대분류 | 선택 항목 | 연계 학습 스크립트 |
| :--- | :--- | :--- |
| **거주지** | 가족과 함께 거주 | 집/방 묘사, 주중/주말 활동, 어릴 적 집 변화, 가족 특별한 기억(케이크), 분리수거 루틴, 방 청소/동생 돌보기 |
| **여가 활동** | 영화보기 | 선호 장르(홈시네마 vs 극장), CGV 최근 관람 경험(오디세이), 티켓 예매 롤플레이, 배우 뉴스(유해진) |
| | 공연/콘서트 보기 | 공원 게릴라 콘서트 라이브 뮤직 경험 |
| | 공원 가기 | 집에서 보내는 휴가(아이들과 공원 자전거/피크닉), 공원 라이브 콘서트 |
| | 해변 가기 | 보령 대천 해수욕장 기억에 남는 경험 (일몰 풍경) |
| **취미** | 음악 감상하기 | 클래식 & 트로트, 스마트폰 스트리밍 앱 청취 루틴, K-pop 입문 및 취향 변화, MP3 플레이어 롤플레이 |
| **운동** | 걷기 / 조깅 | 공원 산책, 가벼운 야외 활동 스크립트 연계 |
| **휴가/여행** | 집에서 보내는 휴가 | 두 아들과 보내는 휴가(만화/보드게임/레고/공원 나들이) |
| | 국내 여행 | 제주도 가족 여행(차은우 목격 에피소드), 조카 돌보기로 여행 취소 에피소드, 어릴 적 설악산 등산 |
| | 해외 여행 | 해외여행 루틴(하이킹, 해변 액티비티, 로컬 푸드 & 쇼핑) |

> 📌 **시험 전략 요약 노트:**  
> - 4가지 카테고리(거주지, 여가, 취미, 휴가)에서 조합되어 3콤보 세트가 출제됩니다.  
> - 준비한 서베이 기반 토픽들이 서로 자연스럽게 연결(예: 공원 ↔ 라이브 콘서트 ↔ 집캉스 ↔ 걷기)되도록 유기적으로 연습할 수 있도록 설계되어 있습니다.
